📚 NOTA TUJUAN SIMULASI & ARAHAN CLI
1. Kenapa Pelajar Perlu Buat Simulasi 3D Ini?

Dalam persekitaran sebenar, sistem pengoperasian rangkaian (NOS) seperti Debian 12 bersifat abstrak dan hanya dilihat sebagai skrin hitam terminal. Simulasi 3D ini dibina untuk:

  • Visualisasi Fizikal & KVM Console: Memberi gambaran sebenar bagaimana juruteknik bergerak di dalam bilik pelayan dan menggunakan stesen kerja PC (Monitor, Keyboard, Mouse) untuk mengawal pelayan.
  • Menghubungkan Teori & Praktikal: Supaya pelajar memahami bahawa setiap arahan CLI yang diketik mempunyai kesan langsung kepada perkakasan pelayan dan talian rangkaian.
  • Persediaan Rangkaian Sebenar: Memahami bagaimana 4 perkhidmatan utama (Main OS, DNS, DHCP, Web) berinteraksi antara satu sama lain.
2. Kenapa Pelayan Perlu Ditetapkan (Setup)?

Pelayan baharu yang baru tiba daripada kilang berada dalam keadaan **KOSONG / UNCONFIGURED** (IP: 0.0.0.0). Pelajar perlu membuat penetapan IP Statik dan memasang servis supaya pelayan ini boleh dicapai oleh peranti pelanggan (*Client*) secara kekal dan stabil dalam rangkaian.

📋 SENARAI ARAHAN CLI MENGIKUT RAK PELAYAN

1. RACK 01 - MAIN SERVER OS (IP: 10.0.0.30):

  • adduser bookworm : Mencipta akaun pengguna tempatan baharu `bookworm`.
  • usermod -aG adm bookworm : Memasukkan pengguna ke dalam kumpulan `adm`.
  • nano /etc/network/interfaces : Menetapkan IP Statik `10.0.0.30/24` pada antaramuka `enp1s0`.
  • systemctl stop apparmor : Hentikan perkhidmatan kawalan keselamatan AppArmor.
  • systemctl disable apparmor : Matikan keupayaan autostart AppArmor.

2. RACK 02 - DNS PRIMARY SERVER (IP: 10.0.0.10):

  • nano /etc/network/interfaces : Menetapkan IP Statik `10.0.0.10/24`.
  • apt install bind9 : Memasang perisian pelayan BIND9.
  • systemctl restart bind9 : Memuat semula perkhidmatan DNS.

3. RACK 03 - DHCP SERVER (IP: 10.0.0.1):

  • nano /etc/network/interfaces : Menetapkan IP Statik `10.0.0.1/24`.
  • apt install isc-dhcp-server : Memasang perisian ISC-DHCP.
  • systemctl restart isc-dhcp-server : Mengaktifkan kolam IP.

4. RACK 04 - WEB SERVER (IP: 10.0.0.20):

  • nano /etc/network/interfaces : Menetapkan IP Statik `10.0.0.20/24`.
  • apt install apache2 : Memasang perisian pelayan web Apache2.
  • systemctl restart apache2 : Mengaktifkan perkhidmatan HTTP Port 80.
