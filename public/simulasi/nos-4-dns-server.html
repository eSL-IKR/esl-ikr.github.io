📚 NOTA TERPERINCI KERTAS KERJA LA 3
1. Apa Itu BIND9?

BIND9 (Berkeley Internet Name Domain version 9) merupakan perisian pelayan DNS *open-source* paling popular dan banyak digunakan di peringkat global. Ia bertindak sebagai "buku telefon rangkaian" yang menukarkan nama domain yang mudah diingati manusia (contoh: dlp.srv.world) kepada alamat IP fizikal komputer (contoh: 10.0.0.30), dan sebaliknya.

2. Kenapa Pelajar Mesti Buat Kertas Kerja LA 3 Ini?

Tanpa perkhidmatan DNS yang dikonfigurasi dengan betul, pengguna rangkaian terpaksa menghafal alamat IP setiap pelayan untuk mengakses perkhidmatan seperti Laman Web atau Pelayan Mel. Kertas kerja ini diwujudkan untuk:

  • Membina Infrastruktur Rangkaian Tempatan: Mengajar pelajar cara menyediakan infrastruktur DNS bagi rangkaian dalaman (*Internal Network*).
  • Menjamin Keselamatan Transaksi Rangkaian: Mengkonfigurasi rekod keselamatan emel (SPF & DMARC) bagi mengelakkan kes penipuan emel (*email spoofing*).
  • Menguasai Teknologi DNS Moden: Mengimplementasikan penyulitan kueri *DNS Over HTTPS (DoH)* untuk melindungi privasi trafik rangkaian daripada diintip (*eavesdropping*).
3. Apa Yang Pelajar Akan Dapat Daripada Simulasi Ini?
  • Kefahaman Visual Nyata: Pelajar melihat secara visual bagaimana nama domain dileraikan (*resolved*) secara *Forward* dan *Reverse* melalui tetingkap *Live Output*.
  • Kemahiran Mengkonfigurasi Fail Zon: Boleh mencipta rekod A, NS, MX, PTR, CNAME, SPF, dan DMARC secara teratur.
  • Pengalaman Praktikal Rangkaian Enterprise: Bersedia untuk mengendalikan pelayan DNS sebenar di industri dengan ketelitian yang tinggi.
📋 SENARAI LANGKAH KERJA KERTAS KERJA LA 3

A. Konfigurasi Internal Network & BIND9:

  • apt -y install bind9 bind9utils : Memasang perisian BIND9 DNS Server dan utiliti kueri.
  • vi /etc/bind/named.conf : Menambah pautan fail zon dalaman named.conf.internal-zones.
  • vi /etc/bind/named.conf.options : Menetapkan ACL network 10.0.0.0/24 dan kebenaran kueri allow-query.
  • vi /etc/bind/named.conf.internal-zones : Mencipta takrifan zon forward (srv.world) dan reverse (0.0.10.in-addr.arpa).
  • vi /etc/default/named : Memaksa BIND berjalan pada protokol IPv4 sahaja (-4).

B. Konfigurasi Zone File & Semakan Resolusi:

  • vi /etc/bind/srv.world.lan : Mencipta fail zon Forward untuk pemetaan Nama Domain ke IP (A Record).
  • vi /etc/bind/0.0.10.db : Mencipta fail zon Reverse untuk pemetaan IP ke Nama Domain (PTR Record).
  • systemctl restart named : Memuat semula perkhidmatan BIND9 untuk mengaktifkan zon baharu.
  • vi /etc/resolv.conf : Menetapkan pelayan pelerai tempatan (*local resolver*) ke 10.0.0.30.
  • dig dlp.srv.world. & dig -x 10.0.0.30 : Membuat ujian resolusi domain dan IP.

C. Alias (CNAME), SPF, DMARC & DoH:

  • ftp IN CNAME dlp.srv.world. : Menetapkan nama alias (CNAME) bagi hos FTP.
  • v=spf1 +ip4:172.16.0.82 -all : Menetapkan rekod TXT SPF bagi mengesahkan pelayan emel rasmi.
  • _dmarc IN TXT "v=DMARC1; p=none;" : Menetapkan rekod TXT DMARC untuk polisi penapisan emel.
  • openssl dhparam -out /etc/bind/dhparam.pem 3072 : Menjana parameter penyulitan keselamatan DNS Over HTTPS (DoH).
