Debian 13 (Trixie) Simulator

Persekitaran Amali Servis Rangkaian Linux

Panduan Amali LA 2 (Web), LA 3 (DNS), LA 4 (DHCP) & LA 5 (LDAP)
Debian 13 CLI
user@debian-client:~

Panduan Arahan Amali

Peringkat: 1. Static IP Taip manual dalam Terminal/VIM
PERINGKAT 1: PERMULAAN & KONFIGURASI IP STATIC

Anda mesti berada dalam mod root dengan menaip su - dan memasukkan kata laluan yang didaftarkan.

Langkah 1: Masuk mod root
su -
Langkah 2: Konfigurasi Debian Repository (Trixie)
vi /etc/apt/sources.list
deb http://deb.debian.org/debian/ trixie main non-free-firmware
deb http://security.debian.org/debian-security trixie-security main non-free-firmware
deb http://deb.debian.org/debian/ trixie-updates main non-free-firmware
apt update
Langkah 3: Sunting fail perkhidmatan rangkaian
vi /etc/network/interfaces
auto enp1s0
iface enp1s0 inet static
  address 10.0.0.30
  netmask 255.255.255.0
  gateway 10.0.0.1

* Selepas taip kod, taip :wq lalu tekan Enter untuk simpan & keluar VIM.

Langkah 4: Restart Rangkaian & Semak IP (Ping Wajib)
systemctl restart ifup@enp1s0
ip a
ping 10.0.0.30
PERINGKAT 2: DHCP SERVER

* Nota VIM: Taip :wq lalu tekan Enter untuk menyimpan fail konfigurasi.

Langkah 1: Pasang ISC DHCP Server
apt -y install isc-dhcp-server
Langkah 2: Tetapkan Interface Listener
vi /etc/default/isc-dhcp-server
INTERFACESv4="enp1s0"
Langkah 3: Konfigurasi /etc/dhcp/dhcpd.conf
vi /etc/dhcp/dhcpd.conf
option domain-name "srv.world";
option domain-name-servers dlp.srv.world;
authoritative;

subnet 10.0.0.0 netmask 255.255.255.0 {
  option routers 10.0.0.1;
  option subnet-mask 255.255.255.0;
  range dynamic-bootp 10.0.0.200 10.0.0.254;
}
Langkah 4: Restart Service & Semak Lease
systemctl restart isc-dhcp-server
cat /var/lib/dhcp/dhcpd.leases
Langkah 5: Ujian Klien Windows
ipconfig /all
ipconfig /release
ipconfig /renew
ping 10.0.0.30
PERINGKAT 3: DNS SERVER (BIND9)

* Nota VIM: Taip :wq lalu tekan Enter untuk menyimpan fail zon.

Langkah 1: Pasang BIND9
apt -y install bind9 bind9utils
Langkah 2: Pautan Fail Internal Zones dalam named.conf
vi /etc/bind/named.conf
include "/etc/bind/named.conf.options";
include "/etc/bind/named.conf.local";
include "/etc/bind/named.conf.default-zones";
include "/etc/bind/named.conf.internal-zones";
Langkah 3: Konfigurasi Internal Zones
vi /etc/bind/named.conf.internal-zones
zone "srv.world" {
    type master;
    file "/etc/bind/srv.world.lan";
};

zone "0.0.10.in-addr.arpa" {
    type master;
    file "/etc/bind/0.0.10.db";
};
Langkah 4: Cipta Fail Forward Zone
vi /etc/bind/srv.world.lan
$TTL 86400
@ IN SOA dlp.srv.world. root.srv.world. (
        2026033001 ; Serial
        3600       ; Refresh
        1800       ; Retry
        604800     ; Expire
        86400 )    ; Minimum TTL
@ IN NS dlp.srv.world.
dlp IN A 10.0.0.30
Langkah 5: Tetapkan Resolv & Restart Service
vi /etc/resolv.conf
nameserver 10.0.0.30
search srv.world
systemctl restart named
dig dlp.srv.world
PERINGKAT 4: WEB SERVER

* Nota VIM: Taip :wq lalu tekan Enter untuk menyimpan fail.

Langkah 1: Pasang Apache2 & PHP
apt -y install apache2
apt -y install php8.2 php-pear libapache2-mod-php
Langkah 2: Aktifkan UserDir & CGI
a2enmod userdir
a2enmod cgid
systemctl restart apache2
Langkah 3: SSL Certbot & WebDAV
apt -y install certbot apache2-utils
htpasswd -c /etc/apache2/.htpasswd debian
a2enmod dav dav_fs
a2ensite webdav
PERINGKAT 5: DIRECTORY SERVER (LDAP)

* Nota VIM: Taip :wq lalu tekan Enter untuk menyimpan fail.

Langkah 1: Pasang OpenLDAP
apt -y install slapd ldap-utils
slapcat
Langkah 2: Cipta Base DN & Pengguna LDIF
vi base.ldif
dn: dc=srv,dc=world
objectClass: top
objectClass: dcObject
objectClass: organization
o: srv.world
dc: srv

dn: cn=admin,dc=srv,dc=world
objectClass: simpleSecurityObject
objectClass: organizationalRole
cn: admin
description: LDAP administrator
ldapadd -x -D cn=admin,dc=srv,dc=world -W -f base.ldif
Langkah 3: Cipta Pengguna LDAP
vi ldapuser.ldif
dn: uid=debianuser,dc=srv,dc=world
objectClass: inetOrgPerson
cn: Debian User
sn: User
uid: debianuser
userPassword: {SSHA}secretpassword
ldapadd -x -D cn=admin,dc=srv,dc=world -W -f ldapuser.ldif
Langkah 4: LDAP Account Manager (LAM)
apt -y install ldap-account-manager
ldapsearch -x -b dc=srv,dc=world
ldapwhoami -x -D "cn=admin,dc=srv,dc=world" -W
